# Snapit docs

Snapit is a Lightshot-style screenshot tool for macOS and Linux: press a key, the screen freezes, drag a box, scribble on it, then copy or save.

**Using the app**

- [Install](./install.md): which file to grab, how to install it, which permission to allow.
- [How to use](./usage.md): selecting, drawing, shortcuts, changing the capture key.
- [Troubleshooting](./troubleshooting.md): the usual hiccups and how to get past them.

**Working on the code**

- [Technical notes](./technical.md): how it fits together, what to be careful with, how to ship a release.
- [Manual test checklist](./testing.md): what still needs trying on real machines.
