# Tài liệu Snapit

Snapit là tool chụp màn hình kiểu Lightshot cho macOS và Linux: bấm phím, màn hình đứng hình, kéo chọn vùng, vẽ vài nét rồi copy hoặc lưu.

**Dùng app**

- [Cài đặt](./cai-dat.md): tải file nào, cài ra sao, cấp quyền gì.
- [Cách dùng](./su-dung.md): chọn vùng, vẽ, phím tắt, đổi phím chụp.
- [Gặp lỗi](./loi-thuong-gap.md): mấy lỗi hay gặp và cách xử lý.

**Sửa code**

- [Kỹ thuật](./technical.md): code chạy thế nào, chỗ nào cần cẩn thận, cách ra bản mới.
- [Checklist test tay](./testing.md): những gì phải thử trên máy thật.
