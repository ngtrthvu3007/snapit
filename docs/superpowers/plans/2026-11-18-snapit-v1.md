# Snapit v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tray-resident Lightshot-style screenshot tool for macOS and Linux (GNOME Wayland primary): hotkey → frozen screen → select region → annotate → copy/save.

**Architecture:** Rust (Tauri 2) captures every monitor with `xcap`, keeps the images in memory, and opens one borderless always-on-top overlay window per monitor. Each overlay loads its frozen image via a custom `shot://` URI scheme and does selection + annotation on a `<canvas>` in vanilla TypeScript. Export is composed in the webview at physical resolution, sent as PNG bytes to Rust commands that write the clipboard or save via a native dialog.

**Tech Stack:** Tauri 2 (`tauri =2.12.5`, `tauri-build =2.7.4`), `xcap 0.9`, `image 0.25`, Tauri plugins (global-shortcut, single-instance, autostart, clipboard-manager, dialog), Vite + TypeScript (no UI framework), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-18-snapit-design.md`

## Global Constraints

- Org rule: npm installs always use `--min-release-age=7` (use `npm`, not pnpm/bun). Cargo has no equivalent: pin `tauri =2.12.5` and `tauri-build =2.7.4` (2.12.6 / 2.7.5 are < 7 days old); commit `Cargo.lock`.
- Targets: macOS 13+ (`"minimumSystemVersion": "13.0"`), Ubuntu 26.04 GNOME Wayland (primary Linux), Linux X11 best-effort.
- Output PNG at physical pixels; filename `Snapit_YYYY-MM-DD_HH-MM-SS.png`; default save dir `~/Pictures`.
- Keys: Cmd/Ctrl+C copy+close, Cmd/Ctrl+S save+close, Esc cancel, Cmd/Ctrl+Z undo.
- Default hotkey: `PrintScreen` (Linux X11), `CommandOrControl+Shift+2` (macOS). Wayland: no global shortcut; `snapit --capture` via single-instance.
- Tray menu: Capture, Start at login (check item), Quit. macOS: no Dock icon (Accessory activation policy).
- Autostart enabled by default on first launch.
- Non-goals: upload, history, blur, Windows, signing/notarization, CI, auto-update.
- The dev machine is a Mac. Linux steps marked **[Ubuntu]** must be run by the owner on their Ubuntu 26.04 laptop; the implementer pauses and asks.

## Review Focus

1. Retina/HiDPI (scale 2.0): exported PNG must be at physical pixels, not CSS pixels → test in Task 5 (`composeExport` scale).
2. Selection dragged right→left / bottom→top: must normalize to a positive rect → test in Task 3 (`normalizeRect`).
3. Click without drag (or < 3 px drag): no selection, never export a 0×0 image → test in Task 3 (`isValidSelection`).
4. Hotkey pressed while overlays are already open: ignore, don't stack a second capture → test in Task 2 (`CaptureGuard`).
5. Text tool committed with empty text: no shape added, Esc while typing cancels only the text box → test in Task 4 (`commitText`).
